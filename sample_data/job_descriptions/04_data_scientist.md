- Python
- SQL
- Data Science

## Preferred
- Tableau
- AWS
- NLP

## Responsibilities
- Build dashboards and analyses for stakeholders
- Develop and validate predictive models
- Communicate findings to non-technical partners
- Maintain data quality in collaboration with data engineering
