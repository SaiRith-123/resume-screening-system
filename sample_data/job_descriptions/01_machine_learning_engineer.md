# Machine Learning Engineer

Department: AI Platform
Seniority: Mid-level
Location: Bengaluru (Hybrid)
Employment Type: Full-time

## About the role
We are hiring a Machine Learning Engineer to design, build and ship ML systems
that power our recommendation and matching products.

## Requirements
- 2+ years of professional experience building machine learning systems
- Strong Python programming skills
- Solid SQL and data manipulation skills
- Hands-on Machine Learning experience (model training and evaluation)
- Bachelor's degree in Computer Science or a related field

## Preferred
- PyTorch
- AWS
- Docker
- Experience deploying models to production (MLOps)

## Responsibilities
- Develop machine learning models for ranking and recommendation
- Build production ML pipelines end to end
- Collaborate with data scientists and backend engineers
- Monitor model quality and drift in production
